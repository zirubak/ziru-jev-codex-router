# Origins and release scope

This repository is based on https://github.com/0xNatoshi/jev-codex-router,
source base `8701ef788aa8cb0948f299538747fb01029d32b8`.
Original copyright and MIT permission text remain in `LICENSE`.
Embedded router provenance and MIT notice remain in `ROUTER_FORK.md` and
`router/LICENSE`; its own upstream installation contract is retained because
its regression suite checks that security contract.

ZIRU adds research-informed model/effort routing, current Luna/Sol/Astra
candidates, Sol/high technical fallback, answer signatures, manual Ultra
advice and installation checks. It does not claim authorship of upstream work.

The release excludes personal agent configuration, raw conversations and
research logs, local caches, environment files, backups and nested Git history.
This preview carries a fresh distribution history, not the private research
repository's history. Existing services are not reinstalled by publishing it.
