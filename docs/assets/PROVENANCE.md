## Quick-start comic

`quickstart-comic.png` was created with the built-in ChatGPT image generation
tool on 2026-10-02 using the owner's Cavemen-ZIRU character as a reference.
No selectable model version was exposed. The four panels and their lettering
were visually inspected before inclusion in both READMEs. The original
reference is not redistributed.

The comic illustrates selection and response labels; it is not a captured
product screen or measured routing result. English dialogue is accompanied by
localized alternative text and an explanatory caption in each README.
Dimensions and checksum are recorded in `manifest.json`.

### Production prompt

Use case: illustration-story. Create an original charming 4-panel newspaper
comic for the GitHub README of ZIRU Jev Codex Router. Reference image is
character reference only: keep the friendly caveman's black rectangular
glasses, wild brown hair, beard, leopard tunic and stone hammer. Simplify him
into expressive hand-inked newspaper cartoon art. Remove Medium lettering
and the circular emblem. Use warm ivory paper, muted copper and slate,
spacious readable speech balloons, and gentle developer humor. No existing
comic characters. Four equal panels left to right, clear borders, approximately
3:1 landscape composition.

1. Caveman at a stone-age laptop with model-choice stones labeled Luna, Sol
   and Astra. Dialogue: "Which model again?"
2. Caveman selects "Jev Codex Router". Dialogue: "Pick once."
3. Two request/result cards: "Fix a typo", "[gpt-6-luna / low]";
   "Review a tricky bug", "[gpt-6.1-sol / high]".
   Dialogue: "Right tool. Right effort."
4. Caveman happily types, using the stone hammer as a paperweight.
   Dialogue: "More coding. Less choosing."

Footer: "Illustrative routes. Actual choices depend on context."
Render exact lettering legibly. Keep all panels visible with generous margins.
No savings percentages, money, speed guarantees, stars, benchmark claims,
extra logos or watermark.

image generation tool and the owner's character reference. No selectable model

inspected. It is an illustration, not a screenshot of the TypeSafe console.

READMEs. Dimensions and checksum are in `manifest.json`.

landscape, ivory paper with copper and slate, preserving the reference
caveman's glasses, hair, beard, leopard tunic and stone hammer. Panel one:
collect a gold key from a laptop marked TypeSafe; caption "1. Get your key";
speech "My little key to Jev!" Panel two: put the key in a locked box marked
"~/.jev.env"; caption "2. Save it privately"; speech "Home sweet home."
Panel three: ask a Codex laptop to install, keeping the box nearby; caption
"3. Ask Codex to install"; speech "Ready. Let’s build something!" Footer:
"Your key stays in your private file. Never paste it into chat."
No actual credentials, Medium lettering, existing comic characters,
watermarks or savings promises.

The key-page link was checked against TypeSafe's official quick-start Markdown
at https://docs.typesafe.ai/introduction/quickstart.md on 2026-10-02.
