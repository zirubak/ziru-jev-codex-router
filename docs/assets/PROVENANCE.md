# Brand assets

Three assets were created with the built-in ChatGPT image generation tool on
2026-10-01 and visually inspected. The tool did not expose a selectable or
verified model version; no “Image 2.5” provenance claim is made.

The owner's Cavemen-ZIRU character was the reference: glasses, wild brown hair,
beard, friendly smile, leopard tunic and stone hammer. Project variants remove
“Medium” and use slate and copper. The original reference is not redistributed.

- `banner.png`: wide README illustration, character guiding three copper paths
  to Luna/Sol/Astra; title “ZIRU Jev Codex Router”, subtitle “Choose the model.
  Match the effort.”
- `mascot.png`: square copper medallion; character holding a stone marked ZIRU.
- `social-preview.png`: 2:1 social composition; title and “Quality-aware model
  and effort routing”, three route markers. Actual pixel dimensions are recorded
  in the release verification; generation requested 1280×640.

All prompts required the reference identity, no Medium lettering, no fabricated
performance figures, no badges, no watermark and no extra logos.
