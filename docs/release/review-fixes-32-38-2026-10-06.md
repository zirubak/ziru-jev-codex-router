Service startup is asynchronous: installation checks that the launchd label's
PID owns port 4319, validates health, and rechecks ownership within a bounded
readiness window. A preexisting unrelated listener is refused before services
are stopped. No broad process-name kill is used.

A configuration conflict does not skip independent profile, state and service
restoration. The transaction completes those safe restoration steps, retains
the current configuration privately when safely readable, and reports the
remaining conflict. Unsafe or unreadable files are never followed; the result
records an unavailable snapshot.
It obtains the exact cleanup projection from the existing cleaner through a
read-only command against the private original snapshot; the expected output
is retained privately with mode 0600. No independent copy of the cleaner's
rules determines rollback ownership.

TOML ownership is checked in parsed table context, excluding markers and headers
inside user strings. Desktop rollback removes the exact expected runtime leaf from its real env
table. It retains the table header, including an empty header, because the
manifest proves the leaf but does not prove who created the table. User
comments, entries, table structure and unrelated formatting are retained;
conflicting ownership reports a conflict.
