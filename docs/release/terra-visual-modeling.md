# Terra visual modeling route

Policy `split-v22-terra-visual-modeling` adds GPT-6.1 Terra (`terra_61`) to
Jev's current candidates. Jev prefers it for image/drawing interpretation,
Blender/CAD modeling and appearance revisions. The choice is semantic; mentioning
CAD does not override required architecture, independent final or risk review.
Those categories still select Astra in Auto/Manual; fixed Sol/Astra routes preserve
the selected model. Auto effort stays adaptive and Manual
preserves the caller's selected effort. Technical failures retain Sol/high in
Auto and the selected effort in Manual. Kill, shadow and native-quota controls
remain in place. Historical `terra` remains an invalid automatic choice.

[OpenAI's announcement](https://openai.com/index/introducing-gpt-6-1-terra/)
describes visual reasoning and computer use, with evaluations that include
turning drawings into 3D models. Aggregate benchmark results do not establish
Blender- or SolidCraft-specific accuracy, manufacturability or local task quality.
Native reopening, geometry, dimensions and export verification remain required.
The dated reference is a public prior, not measured local calibration. The public priors
are compressed within the existing 3000-character decision dossier budget.

Local HTTP tests exercise the outgoing typed question contract, Terra execution,
canonical replay, exact Manual effort and mandatory Astra precedence. Synthetic
judge answers verify wiring, not live semantic selection or upstream model
availability. The offline cases also cover photo modeling, technical drawings,
CAD risk review and approved export. Live classification and actual model
completion must be reported separately by the release owner.

Terra reports as a native model with its own route label. Unknown subscription
credit rates remain unknown; published API prices are not subscription rates or
measured savings. This change does not add a separate fixed Terra picker.

No durable learning: the behavior and limits are recoverable from the policy,
tests and this release note.
