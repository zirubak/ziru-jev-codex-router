# ZIRU Jev Codex Router v0.1.0-preview.1

First private preview · October 2, 2026

Select **Jev Codex Router** in Codex Desktop and keep coding. TypeSafe's Jev
chooses a model and reasoning effort as the work changes, with the goal of
meeting the task's quality needs while avoiding unnecessary total token use.

## What's included

- Automatic routing among **GPT-6 Luna, GPT-6.1 Sol and GPT-6 Astra**.
- Research-informed model and effort selection for implementation, architecture,
  review and continuation requests.
- Optional visible **[model / effort]** labels at the start of response text.
- **GPT-6.1 Sol / high / Standard** technical fallback for Jev communication or
  response-validation failures and missing key/task cases. Kill switch, shadow
  mode and quota exhaustion retain their separate behavior.
- Manual **Ultra recommendations** when independent parallel work could help.
  The router does not automatically enable Ultra or delegation; the current
  recommendation text is Korean.
- Direct TypeSafe API calls, a bounded routing dossier and preservation of the
  complete canonical request for the selected execution model.
- An embedded router, macOS launchd installation, preflight checks and
  transaction backups with restoration on installation failure.
- Status, doctor and smoke diagnostics, plus update and removal instructions.
- English and Korean READMEs with a real model-picker screenshot, prompt and
  response examples, Mermaid architecture, installation prompt and caveman
  comics explaining everyday use and private API-key setup.

## Getting started

This preview requires repository access, macOS Codex Desktop with a working
ChatGPT login, **Node.js 22.19+**, **Python 3.11+**, and a TypeSafe API key.

1. Get a key at https://console.typesafe.ai/keys and save it privately in
   `~/.jev.env` under `TYPESAFE_API_KEY`, with file permissions `600`.
   Never paste the key into chat or an issue.
2. Follow the README's **Ask Codex to set it up** prompt, or clone this repository
   to permanent internal storage and use the root `./install.sh`.
3. Run the documented status, doctor and smoke checks, then quit and reopen
   Codex yourself. Select **Jev Codex Router** in your chat's model menu.

Existing native models remain available. Choose one in the same menu whenever
you want to stop automatic routing for that chat. Installation includes a live
smoke request and may consume usage.

## Validation and known limitations

Release source: `cf7c6c0b2ced07aa40b8c39f777c9dec8b9a18f2`.

[CI run 37034351284](https://github.com/zirubak/ziru-jev-codex-router/actions/runs/37034351284)
passed both Python lanes (Ubuntu 3.11 and macOS 3.12), embedded router lanes on
Ubuntu and macOS, and the pinned Codex app-server contract. The Windows lane
was still running at publication preparation; no Windows result is claimed.
Windows CI is retained as portability feedback and is not a completion gate
for the owner-approved macOS preview.

- **Windows and Linux whole-product installation are not supported by this
  preview.** The root installer uses macOS launchd. Portable router tests do
  not establish full product support. Windows testers are welcome to provide
  sanitized feedback through Issues.
- Earlier release qualification covered isolated installer checks and
  `--prepare-only` from the distribution checkout. This release does not claim
  a fresh live installation from the tagged checkout or change the owner's
  running services. A health response alone does not prove installation.
- **No reliable savings percentage or currency estimate is published.** Current
  rates, incomplete usage and the cost of retries/TypeSafe decisions prevent
  a whole-task savings claim. Subscription fees, Codex credits and API cost
  estimates are different quantities.
- Route examples and comics are illustrations, not guaranteed model choices.
  A Sol/high label by itself does not prove fallback occurred.
- The repository remains private. GitHub reported secret scanning unavailable
  for this repository; local secret checks and private runtime exclusions are
  retained. No GitHub push-protection claim is made.
