# ZIRU Jev Codex Router v0.1.0-preview.2

Second private macOS preview — prepared October 2, 2026.

This preview adds separate Auto/Manual selection, isolates Jev from official
Codex traffic, and fixes Desktop effort/context handling, native collaboration,
and first-time installation. It remains a private prerelease.

## Changes since preview.1

- **Auto and Manual**: Auto chooses both model and effort. Manual chooses a
  compatible model while retaining low, medium, high, xhigh or max. Jev does
  not execute Ultra automatically.
- **Official-provider isolation**: ordinary Codex keeps its built-in provider
  and catalog. CLI routing uses `codex -p jev`. The optional Desktop launcher
  exposes Auto/Manual without changing the original signed app bundle or
  globally redirecting OpenAI traffic. [Isolation](provider-isolation.md),
  [selection modes](selection-modes.md).
- **Desktop effort and context**: preserve the Jev alias through effort-only
  notifications; use known native carrier metadata to avoid premature repeated
  compaction; persist verified per-thread mode and effort. Recheck supported
  app/native pins on respawn. [Desktop contract](native-desktop-bridge.md).
- **Adaptive native Plan mode**: choose capability and depth for uncertainty,
  dependencies and failure consequences rather than fixing every plan to
  Astra/max. Bounded review recommendations confer no delegation authority or
  proof of review. [Plan policy](adaptive-planning.md), [PR #1](https://github.com/zirubak/ziru-jev-codex-router/pull/1).
- **Native collaboration**: omitted models and matching Jev aliases preserve
  native carrier/provider inheritance; encrypted handoffs reach the native
  executor. Keep V2 compaction and destination-specific quota failover behavior.
  [Issue #8](https://github.com/zirubak/ziru-jev-codex-router/issues/8),
  [PR #10](https://github.com/zirubak/ziru-jev-codex-router/pull/10),
  [validation](jev-collaboration-2026-10-02.md).
- **Official Ultra**: preserve official Ultra settings and reject unsupported
  values before switching Jev threads; include the recommended model in manual
  Ultra advice. [Issue #5](https://github.com/zirubak/ziru-jev-codex-router/issues/5),
  [validation](issue-5-official-ultra-2026-10-02.md).
- **Quota safety**: refuse unsupported Responses-lite external fallback before
  execution, preserving tools rather than silently dropping them.
  [PR #9](https://github.com/zirubak/ziru-jev-codex-router/pull/9),
  [validation](lite-quota-contract-2026-10-02.json).
- **Fresh installation**: register Jev before first embedded setup; on existing
  installations restore service definitions before provider commands that can
  restart services. [Issue #2](https://github.com/zirubak/ziru-jev-codex-router/issues/2),
  [PR #11](https://github.com/zirubak/ziru-jev-codex-router/pull/11),
  [validation](issue-2-fresh-install-2026-10-02.md).

## Install and update

Requires macOS, a working Codex ChatGPT login, Node.js 22.19+, Python 3.11+,
and a privately stored TypeSafe key. Follow the [English guide](../../README.md)
or [Korean guide](../../README.ko.md). Never paste credentials into chat or Issues.

Use the root `./install.sh` transaction from a stable checkout. For optional
Desktop integration, use `./install.sh --desktop`, save your work, quit Desktop
yourself, then open the generated `Jev Codex.command` launcher. Opening the
original app normally retains the official connection. The CLI profile remains
available via `codex -p jev`.

For an existing installation, use `bin/jev-codex-router update`, then run the
root `./install.sh --desktop` separately if opting into Desktop integration.
The updater does not forward `--desktop`. It follows repository main, not a preview tag. A source checkout may
therefore be newer than this preview; inspect its commit before reporting a
version. Preserve private config, credentials and protected backups. Do not
restore a historical config wholesale. [Operations](../../server/INSTALL.md).

## Known limits

- Full-product Linux and Windows installation is unsupported. Conditional skips
  and unexecuted platforms remain coverage limits, not passing results.
- Desktop integration is an internal, build-specific adapter, not an official
  extension API. Pins cover Desktop build 12776 / bundled CLI
  `0.159.0-alpha.12.1`; a changed build opens ordinary Codex without the adapter.
  Account allowlist filtering can hide Jev entries.
- The latest fresh-install correction has isolated transaction and real CLI
  registration coverage. A complete fresh live installation/update from this
  exact release source has **not** been performed; actual launchd/credential-store
  rollback is not certified by synthetic tests. Release publication readiness
  is separate from successful draft preparation.
- Responses-lite external quota fallback returns **HTTP 503**; ordinary supported
  Responses fallback remains separate. Actual official Ultra inference and
  delegation have not been verified.
- Opaque child task text may use the existing technical route. Collaboration
  success does not prove child-specific semantic selection by Jev.
- Response labels describe the selected route. They are not backend-confirmed
  identity when returned metadata is missing or disagrees; screenshot-to-item
  correlation remains a UI coverage limitation.
- No reliable whole-task quota, token-savings percentage or currency estimate is
  claimed. TypeSafe costs, subscription charges and Codex credits are distinct.
- The repository stays private. Credentials, transcripts, private logs and
  installation backups are excluded; no new visibility or security-setting
  changes are made.

Original MIT notices and embedded fork provenance are retained. The embedded
router's `0.6.0` package version and server protocol `1.5` are independent of
this monorepo release tag.
