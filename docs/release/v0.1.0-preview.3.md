# ZIRU Jev Codex Router v0.1.0-preview.3

First public macOS source preview — October 11, 2026.

This release hardens gateway request boundaries and updates vulnerable
dependencies before public distribution. It also includes the Desktop, quota
recovery and fixed-model routing changes merged since preview.2. This is a
prerelease; the limitations below are part of its support contract.

## Changes since preview.2

- **Gateway security:** reject caller-supplied transport, credentials and routing
  overrides before a request reaches LiteLLM, including compaction and failover.
  Native Jev/DeepSeek canonical requests, tool schemas and inference options
  retain their existing behavior. The gateway also disables client credentials.
- **Cursor edge resilience:** malformed Host/URL input returns HTTP 400 while
  the listener continues serving subsequent requests.
- **Dependencies:** LiteLLM 1.96.2, multidict 6.9.1, oauthlib 4.0.0, PyJWT 2.15.1
  and urllib3 2.8.0 in the universal hash lock; Electron 43.7.9 and compatible npm
  fixes. FastAPI and cryptography security/compatibility constraints are retained.
- **Fixed-model effort routing:** Jev Sol and Jev Astra let users choose the
  model while Jev selects effort. Auto/Manual remain separate. See
  [PR #44](https://github.com/zirubak/ziru-jev-codex-router/pull/44) and
  [boundary fixes #45](https://github.com/zirubak/ziru-jev-codex-router/pull/45).
- **Desktop recovery:** qualify native contracts on app updates, preserve safe
  recovery, resume unloaded chats, handle checkpoint summaries and historical
  aliases, and restore trusted app tools. See the
  [Desktop contract](native-desktop-bridge.md).
- **Quota and installation:** recover Responses-lite after a native quota reset,
  preserve canonical replay/manual dry protection, and wait for launchd removal
  during updates. See [quota evidence](lite-quota-recovery-2026-10-08.md) and
  [review fixes](review-fixes-32-38-2026-10-06.md).
- **Public documentation:** use this fork's private security reporting link,
  disclose the retired hook's raw-text logging, and distinguish upstream
  installation artifacts from the supported Jev root transaction.

## Install and update

Requires macOS, Node.js 22.19+, Python 3.11+, a working Codex ChatGPT login and
a privately stored TypeSafe key. Follow the [English guide](../../README.md)
or [Korean guide](../../README.ko.md). Use the root `./install.sh` transaction
from a stable checkout. For this exact release, check out `v0.1.0-preview.3`.

The supported updater `bin/jev-codex-router update` follows `main`, not the
latest tag. Apply optional Desktop integration with `./install.sh --desktop`
separately; save work and restart Desktop yourself. Preserve local modifications,
credentials and protected backups. Publication does not update an installed
service automatically. [Operations](../../server/INSTALL.md).

## Dependency audit and known limits

Python has **0 known vulnerabilities** in both the 106-package macOS audit and
the separate universal-lock audit (111 distributions, 114 name/version pairs,
no skipped entries). The latter checks advisory data for every platform branch;
it does not certify installation on those platforms. npm has **0 high/critical
findings**, but its full audit is not zero:

| Component | Remaining audit findings | Verified boundary |
| --- | ---: | --- |
| Control Center | 8 moderate | One `sprintf-js` advisory propagated through builder dependencies; affected packages are absent from the packaged app archive |
| Static docs | 10 moderate | One `postcss-selector-parser` advisory propagated through the CSS build chain; the site emits static files |

The [sprintf-js advisory](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)
has no patched release. Its inspected build callsites use literal format strings.
The [CSS parser advisory](https://github.com/postcss/postcss-selector-parser/security/advisories/GHSA-rj75-hqrm-r3gf)
is fixed on a newer major outside the installed build tool's declared range.
No forced downgrade, unsupported override or audit suppression was used. No
reachable application-runtime exploit was identified for these remaining paths;
untrusted future build inputs can still create build risk.

- Desktop Plan selection can reset with Jev; [issue #30](https://github.com/zirubak/ziru-jev-codex-router/issues/30)
  remains open. This release does not claim that UI acceptance is complete.
- Direct requests to the internal LiteLLM port with forbidden overrides are
  blocked before upstream dispatch but can return 500 because upstream error
  handling imports optional `prisma`. Directly selected gateway transport/routing
  overrides return 400 at the router. A failover rejection can preserve the
  original upstream error (429 in the isolated proof), without dispatching to
  the gateway. Metadata callback controls rely on LiteLLM's fail-closed checks
  and can retain its 500 error-format limitation.
- Full live launchd/credential-store install/update/rollback of this exact
  candidate was not performed. Isolated tests do not certify production state.
- Linux, Windows and Intel macOS product installation were not qualified here.
  No signed/notarized binary is distributed. GitHub's source archives are the
  release distribution; embedded upstream Homebrew/download artifacts are not.
- Star History's current integration was checked, but the chart endpoint was
  inaccessible in this environment (HTTP 403 / browser client block). No token
  was created and no successful README chart render is claimed.
- Model labels are selected-route metadata, not proof of backend identity.
  No whole-task token/quota savings percentage is claimed.

MIT notices and fork provenance are retained. The embedded router's `0.6.0`
package version is independent of this monorepo release tag.
